## v1.1 internal review pass (pre-submission)

Before this candidate was pushed, the final diff went through a four-dimension
review (security, correctness, intended-vs-implemented, maintainability), each
finding adversarially verified by an independent agent, plus the repo's
gstack pre-landing checklist pass. 17 findings were confirmed and ALL were
fixed in the review-fix commit, with regression tests where code changed.
The two highest: (1) `listCommits` used 0x1e as its record delimiter, and a
literal RS byte in a commit message silently truncated the audited message —
an audit bypass; records are now NUL-terminated (`git log -z`), which git
guarantees cannot collide with message bytes, and a reproduction test pins
it. (2) The workflow's `pnpm/action-setup` had no root `package.json` to
read (both checkouts are pathed) and would have failed on every run; it now
resolves the pnpm version from the policy tree's manifest. Also closed:
checker crashes were silently green behind `| tee` (pipefail now explicit),
recursive AST walk RangeError'd on ~5k-deep nesting (iterative now, parser
blow-ups degrade to a PRX-B-SIZE finding), the mood heuristic missed a
copula as the first description word, trailer continuation lines lost the
wrap exemption, the Evidence length cap existed on only one surface (shared
grammars now live in rules.mjs), REQUIRED_SECTIONS gained a live-template
drift guard, the fixture manifest gained an integrity test, and the threat
model was corrected to match the implementation (`base/` directory, real
rule ids, the honest A8 parse-cost residual, the workflow_dispatch
fallback, and the bash mirror of policy-source.mjs).
