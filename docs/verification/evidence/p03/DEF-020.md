# DEF-020 — P03.CP01 evidence written with silently dropped content

| Field | Value |
| --- | --- |
| Detected by | P03.CP01 (review of the emitted checkpoint) |
| Severity | MEDIUM |
| Affected gate | P03.CP01 evidence |
| Status | CLOSED |

## What happened
`CP01-checkpoint.md` was generated with an UNQUOTED heredoc (`<<EOF`) because
the document interpolates live hashes. zsh therefore treated the document’s
backtick-quoted terms as command substitution, executed them, and inserted
their (empty) output. Three phrases lost their technical terms:

```
NEG04 `LEDGER_TAMPERED` on live bytes. NEG05 `RENDER_DRIFT` on hand-edited markdown.
  ->  NEG05  on hand-edited markdown.

Additive `migrate` added `gate_results` and `result_schema_version` while ...
  ->  Additive  added  and  while ...
```

The shell also printed `command not found: LEDGER_TAMPERED` etc., which is how
this was caught.

## Why MEDIUM
The checkpoint’s decision, hashes, counts and audit results were unaffected, and
the ledger stayed internally consistent (the recorded hash matches the file as
written). But the mandate requires negative tests to be reported BY DECLARED
REASON, and the corrupted lines dropped exactly those reason tokens. Evidence
that omits the reason is weaker than evidence that states it, even when the
underlying test passed — and the sweep transcript independently records both
`LEDGER_TAMPERED` and `RENDER_DRIFT` firing.

## Scope check (not assumed — measured)
Every earlier checkpoint was scanned for the same symptom:
pboot/CP01, p00/CP01, p00/CP02, p01/CP01, p02/CP01 and the three addenda all
report zero suspicious lines and retain 29–56 backticked terms each. In those
documents the backticks were escaped (`\``). **The corruption is isolated to
p03/CP01.**

## Correction
`CP01-checkpoint.md` is sealed — its hash is recorded as P03.CP01 evidence, and
editing it would trip STALE_EVIDENCE and destroy the audit chain. The corrected
rendering is therefore appended as `CP01-corrected.md`, which restores the three
damaged lines verbatim.

## Root-cause prevention
Documents containing backticks are no longer produced by shell heredocs.
`CP01-corrected.md` and this record were generated by Node with the values
passed as data, so no shell metacharacter in the document body can ever be
evaluated.

## Retest
`grep` for the symptom across all checkpoint evidence: only the sealed
p03/CP01 matches; the corrected rendering contains all three restored lines.
`ledger verify` exits 0.
