# DEF-021 — interrupted run could publish a completed-looking record

**Severity:** HIGH (false-completion enabler)
**Detected by:** P04.NEG03 / P04.CLN01, first execution of the declared suite
**Affected:** `scripts/ci/executor.mjs` (P04.T09 completion path),
`scripts/ci/teardown.mjs` (signal wiring)

## DETECT

First run of the P04 suite (3 failures / 52). NEG03 observed
`manifest_exists=true` and `readExecutorEvidence` succeeding on a SIGINT'd
run; CLN01 iteration 1 observed the same. Exact assertion output preserved in
`raw/DEF-021-detect.txt`.

## ROOT CAUSE

Two coupled races, one cause: **the signal handler's teardown is async, and
nothing stopped the main flow from continuing while it awaited.**

1. On SIGINT the handler ran `runAll()` (async). While it awaited, the
   SIGTERM'd children's `exit` events resolved the pending `runCommand`
   promises, `runGraph` settled, and `execute()` reached the results +
   manifest writes **before** `process.exit(130)` fired. An interrupted run
   produced a byte-valid, hash-consistent, `complete: true` record.
2. The first repair attempt (throw `RUN_INTERRUPTED` at the completion
   guards) moved the race instead of ending it: the throw landed in the
   embedding driver's catch, whose `process.exit(3)` **preempted the still
   running teardown** — non-zero exit, no manifest, but a leaked tmp dir
   (CLN01 iteration 1 `tmp_dir_exists=true`).

## CORRECT

- `TeardownRegistry.wireSignals` gained a SYNCHRONOUS `onSignalStart` hook,
  invoked before the first await in the handler; the executor latches
  `this.interrupted` there and journals `INTERRUPT_SIGNAL`.
- Both completion guards in `execute()` check the latch and **park**
  (`await new Promise(() => {})`) instead of throwing: once interrupted, the
  signal handler owns process termination, so the main flow can neither
  publish a record nor hand its caller an exit path that races teardown.

## RETEST

- Targeted: NEG03 — exit 130, children dead, zero marked processes, zero
  lane locks, tmp removed, **no manifest**, `readExecutorEvidence` refuses
  with `INCOMPLETE_RUN`, `INTERRUPTED` event present.
- Relevant regression: full P04 suite 52/52, then 3 further consecutive
  full-suite runs, all 52/52 (zero flakes).
- Negative retest (the fix can fail): CLN01 runs the interrupt path 10/10
  with per-iteration independent assertions — any reappearance of either
  race fails the suite loudly; both original failure signatures are the
  pinned assertions.

## CLOSE

Closed with corrective action shipped in the same phase, regression anchored
by the two mandatory units that detected it (NEG03, CLN01).
