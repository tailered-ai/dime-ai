# DEF-013 — P01 evidence asserted absolute resource baselines instead of deltas

| Field | Value |
| --- | --- |
| Detected by | P01.NEG02 |
| Severity | MEDIUM |
| Affected gate | P01.NEG02 / P01.REG01 / P01.CLN01 evidence |
| Status | CLOSED |

## What happened
The first NEG02 transcript annotated two checks with absolute expectations:

    worktrees registered = 39 (expect 1 = main only)
    git stash list       = 1  (expect 0 — nothing was stashed)

Both "expected" values were invented rather than measured, so the transcript
reads as two failures when in fact nothing was wrong.

## Ground truth, established from the repository
- **39 worktrees are PRE-EXISTING.** `git worktree list` shows registrations
  created by earlier sessions under
  `/private/tmp/claude-501/.../scratchpad/wt-*`, on unrelated branches
  (`closure/session2-nfl-db-*`, `fix/nfl-db-t4-cache-and-content-pin`,
  `feat/m203-dry-run-harness`, `harden/schema-closeout`,
  `security/edge-identity-remediation-v2`, …). `git worktree prune --dry-run`
  reports nothing prunable. **Zero were created by P01**, and
  `.ci-verify/runs/` is empty — the P01 run worktree WAS disposed correctly.
- **The stash predates this work.** `stash@{0}` is dated 2026-08-06 on branch
  `security/permissions-policy-header` ("pre-remediation-2026-08-06"). P01
  never stashes; `--committed` mode exists precisely so it does not have to.

## Why this is a real defect, not a nitpick
P01.REG01 requires proving that "the registered worktree count and residual
resource inventory return to baseline after every run". A hard-coded absolute
expectation cannot express that: it would fail forever on this machine while
saying nothing about whether P01 leaks. The correct instrument is a DELTA
against a measured baseline.

## Corrective action
1. Measure the baseline (worktree count, `.ci-verify` run count, stash count)
   BEFORE the exercise and assert `delta == 0` afterwards.
2. Never annotate an expectation that was not derived from the repository.

## Retest
NEG02 transcript regenerated with measured baselines and deltas; REG01 and
CLN01 both instrumented the same way and track every iteration individually.
