# DEF-003 — the P02 contract extractor has no declared YAML parser

| Field | Value |
| --- | --- |
| Detected by | P00.T04 |
| Severity | MEDIUM |
| Status | **OPEN — OWNER DECISION REQUIRED** |
| Affected gate | P02.T01 / P02.T05 (contract extraction) |

## Root cause
P02 requires a real YAML parse — its own contract states that an unsupported
construct must abort generation rather than be partially interpreted, which a
regex scanner cannot guarantee. No parser is reachable:

| Runtime | Probe | Result |
| --- | --- | --- |
| Node | `import("js-yaml")` | `ERR_MODULE_NOT_FOUND` |
| Node | `import("yaml")` | `ERR_MODULE_NOT_FOUND` |
| Python | `import yaml` | ModuleNotFoundError (PyYAML absent) |

`package.json` mentions `js-yaml` only as a pnpm **override** for transitive
consumers (`">=4.3.1 <5.0.0"`), which does not make it importable.

The P00.T04 census was produced by importing js-yaml 4.3.1 through its pnpm
store path — a phantom dependency. That is adequate for a one-off, checked-in
census artifact; it is NOT an acceptable foundation for a gate, because any
future install or dependency bump can remove it.

Note the repo's own `check-github-actions-security.mjs` faced this and chose a
"dependency-free block-scope scanner" (its line 192). That choice is why the
gate scans raw text and why a `secrets.NAME` literal in a comment trips it.

## Blast radius
P02 cannot be implemented to its stated fail-closed standard until resolved.
P01 is unaffected.

## Corrective action — OWNER DECISION, outside this execution's authority
Exactly one of:
- **(A)** Declare a pinned YAML parser as a `devDependency` in its own PR.
  Touches `package.json` + `pnpm-lock.yaml`, so it passes through OSV,
  dependency-review, and the frozen-install gate. Recommended.
- **(B)** Treat the parser as a P06-class pinned external tool fetched by
  `tools-sync` with checksum verification, keeping the dependency graph
  untouched.
- **(C)** Build the extractor on a dependency-free scanner, accepting that
  "every construct class counted" degrades to "every construct class the
  scanner knows about" — which contradicts P02.T05 and is not recommended.

## Regression test (after the decision)
P02.NEG01 (non-allowlisted construct aborts generation with no partial file)
is only meaningful once the parser can see the whole document tree.

## Retest result
Not yet retestable. Blocked on the owner decision.
